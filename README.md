# Movie Ticket Booking System

A console-based Movie Ticket Booking System developed in C++ using Object-Oriented Programming concepts.

## Features
- View available movies
- View detailed movie information
- Book movie tickets
- Generate booking bill
- View booking details using Booking ID
- Cancel booked tickets
- Automatic booking ID generation

## Concepts Used
- Classes and Objects
- Constructors
- Encapsulation
- Vectors
- Functions
- Loops and Conditional Statements
- Basic Input/Output

## How to Run
1. Download or clone this repository.
2. Open `Movie_Ticket_Booking_System.cpp` in any C++ compiler.
3. Compile and run the program.
4. Select an option from the menu.
